# 09. Technical Architecture (plan only, not implemented)

## Principles
Fast on mid-range Android over 4G, mobile-first (most traffic will arrive from Instagram), static, cheap to host, easy for the owner to update.

## Stack
| Concern | Recommendation | Why |
|---|---|---|
| Framework | **Astro** (static output) with a small amount of vanilla JS | Ships near-zero JS by default. One page. Easy components |
| Styling | **Tailwind CSS** or plain CSS with variables for brand tokens | Quick, consistent; tokens from 04 |
| Alternative | Plain HTML/CSS/JS | Equally valid for one page. Choose if the owner will edit the files himself |
| Language | Astro i18n or two static pages (EN/TA) if Tamil approved | Pending decision |
| CMS | None at launch. Content in a single data file | Keep simple. Revisit if gallery updates become frequent |

## Component architecture
`Header` (logo, WhatsApp) · `Hero` (video + CTAs) · `ProofBar` · `Services` · `ProjectCard` / `ProjectGrid` · `BeforeAfter` · `VideoShowcase` (`LiteYouTube`) · `Process` · `About` · `Academy` · `Testimonials` (only if real) · `Contact` (map, form, hours) · `FloatingWhatsApp` · `Footer`. Content (services, projects, links) in one JSON/TS data file.

## Responsive strategy
Mobile-first breakpoints (360 / 768 / 1024 / 1440). Single column mobile, sticky bottom WhatsApp/call bar, touch targets ≥ 48 px, `clamp()` type scale, test at 360 px.

## Performance targets
Lighthouse mobile ≥ 90, LCP < 2.5 s, CLS < 0.1, total initial weight < 1.5 MB excluding the deferred hero video.

## Image optimisation
AVIF/WebP with JPEG fallback, `srcset`, explicit width/height, `loading=lazy` below the fold, the LCP image preloaded (use the hero **poster**), generated by Astro image tooling or sharp.

## Video optimisation
- Hero: self-hosted 5–10 s loop, **muted, playsinline, no audio track**, H.264 MP4 plus WebM, ≤ 1.5 MB (720p, 24 fps), poster image shown first, not loaded on `prefers-reduced-motion` or Save-Data.
- Project videos: **lite-youtube facade** (thumbnail until click) so no YouTube JS loads upfront.
- **Avoid Instagram embeds** (heavy, third-party scripts, tracking). Use link cards with a static thumbnail.
- Source from **original files** (see 07).

## SEO
Single `<h1>`, descriptive title/description (Chennai, airbrush, hydro dipping, Tambaram/Chromepet), Open Graph/Twitter cards, `LocalBusiness` JSON-LD (name, address, phone, sameAs Instagram/YouTube; hours when known), sitemap, robots, canonical, descriptive alt text. Create and link a **Google Business Profile** (none found). Do not add review markup unless real reviews are displayed.

## Contact and WhatsApp
- Primary: `https://wa.me/919677184462?text=<url-encoded prefilled message>` (service/bike-model variants).
- `tel:+919677184462`.
- Optional enquiry form: Formspree/Web3Forms (no backend) forwarding to the owner's email and/or WhatsApp. Honeypot spam protection. **Email needed from the owner.**
- Map: link out to Google Maps (or a lazy-loaded embed) once the pin is confirmed.

## Analytics and privacy
Plausible or Umami (light, cookie-less) or GA4. Track WhatsApp clicks, call taps, form submits and video plays as events. Short privacy note in the footer.

## Hosting
**Cloudflare Pages** (free, global CDN, custom domain, auto-deploy from Git). Alternatives: Netlify, Vercel. Needs a **domain** (e.g. kccustoms.in), ownership and registrar access from the owner. Videos can go to Cloudflare R2 or be kept in the repo if small.

## Security / quality
HTTPS, security headers, no secrets in the client. Basic a11y checks (contrast, focus, keyboard), cross-browser test including low-end Android.
